# Auto-alt text

If you want the code it's in the packages folder.

## Generic alt text

Makes alt-text for any html file using the LLM provider of your choice.

After chatting with people at the conference I have made a version (unchecked) that *should* work when pointed at any `html` file (actaully any folder structure containing `html` files). 
If you want to convert something that isn't `html` you could always use [pandoc](https://pandoc.org/) to convert it to html first. However, if you've got a bnch of stuff drop me a line (edrs20@bath.ac.uk) and I'll help you automate it.
